# Фиды товаров Max Moda для Яндекс Бизнеса

Каждые 3 часа GitHub забирает товары с сайта maxmoda.ru (каталог Тильды) и публикует два YML-фида:

- `marella.yml` — товары Marella → карточка Marella (ТРЦ «Море Молл»)
- `maxmoda.yml` — остальные бренды → карточка Max Moda (Навагинская, 3/4)

В фиды попадают только модели в наличии и с фото. Ссылки ведут на карточки моделей на сайте с UTM-метками
(`utm_source=yandex_business`), поэтому переходы и звонки видно в Яндекс Метрике.

Если сайт временно не отвечает или вернул слишком мало товаров, фид не перезаписывается — остаётся прошлая версия.

Запустить обновление вручную: вкладка **Actions** → «Обновить фиды товаров» → **Run workflow**.
